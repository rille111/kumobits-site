Services

What we do

Cyber defense consulting

Reviewing architecture, cloud configuration and deployment pipelines to find weaknesses and reduce attack surface. Practical hardening advice for Azure, Google Cloud, Kubernetes and container platforms.

Secure development and code review

Security focused review of application code and infrastructure as code, and fixing the issues found. Secure design of integrations, authentication and data flows.

Vulnerability remediation

Triage of findings from scanners, audits or disclosure reports, then prioritized, tested fixes in the client codebase with clear documentation of what changed.

Frontier AI models for defense

Principles

How we work

Only authorized work. Every engagement has a written scope and the explicit permission of the system owner before any testing or review starts. We do not test systems without that authorization, and findings are shared only with the client. Vulnerabilities found in third party software are reported to the vendor through coordinated disclosure.

Our own security controls

  • Single sign on for company systems.
  • Multi factor authentication is enforced, using hardware security keys.
  • Least privilege access: accounts and tools get only the access the work requires.
  • API keys and credentials are kept in a 1Password vault, with rotation and revocation.
  • A documented incident response process.
  • Work communication uses company domain email only.
  • Managed devices with disk encryption, regular patching, endpoint protection and central management.

Confidentiality

Client work is carried out under a non disclosure agreement. Client names and engagement details are not disclosed, and confidential information is handled discreetly, shared only with those who need it for the assignment and returned or deleted when the engagement ends.
